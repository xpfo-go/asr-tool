# 2026-10-16 Code Review

This maintenance review uses OpenCodeReview 1.13.0 and targeted regression tests.
It changes reliability and packaging; it does not claim new ASR accuracy scores.

## CI Failures

GitHub run [38869025718](https://github.com/xpfo-go/asr-tool/actions/runs/38869025718)
exposed the following failures in public error annotations:

- `installer-tests.log`: `rg: command not found`. Installer tests now use the
  standard `grep` utility, with no ripgrep dependency.
- Windows CMake selected Visual Studio 18 2026 / MSVC 19.51 with CUDA 12.4 and
  failed with `No CUDA toolset found`. CI now pins Windows Server 2022, the
  Visual Studio 17 2022 generator, and CUDA 12.8.1. Linux uses Ubuntu 24.04
  explicitly. NVIDIA's [Windows installation guide](https://docs.nvidia.com/cuda/archive/12.8.1/cuda-installation-guide-microsoft-windows/index.html)
  documents Visual Studio 2022 support.

Local reproduction with Bash 5.3 also found uninitialized `detected` and
`status_message` variables under `set -u`. These failed before the missing
`rg` call; macOS's Bash 3.2 had not exposed them. Arrays and menu state are
now initialized explicitly. The existing Linux PTY closure regression check
also handles `EIO` and requires a successful child exit.

Repair run [38870503343](https://github.com/xpfo-go/asr-tool/actions/runs/38870503343)
passed the evaluation job and all three native build/test jobs. Further model
preparation fixes have their own CI run; publication requires a successful run
for the exact release commit.

## Triage Boundaries

OCR raised three queue hazards involving callback reentry, concurrent `finish`
calls, or submissions racing with `finish`. The application stops and joins
capture before closing the streaming producer and review queue. Its sink only
writes output. These unsupported call patterns do not occur in the application;
the queue ownership and callback restrictions are now explicit in `live.hpp`.
Streaming callback reentry has an explicit runtime rejection and a regression
test because it can invalidate an active native stream.

The new tests use fixtures and native API stubs. No microphone or private
meeting recording is used. Public accuracy measurements in `EVALUATION.md`
remain tied to their recorded executable/model fingerprints, not this repair
build. NVIDIA inference performance and physical microphone behavior are not
covered by these tests.

Default-model validation detects length mismatches, not same-length corruption.
Custom model variants retain the size sanity check and are validated by the
native loader when opened. CoreML preparation checks required files and stages
successful extraction; it does not independently verify every model tensor.
