# 本地会议识别：论文与实现取舍

检索日期：2026-10-16。目标仍是本机运行、沿用可选 `-p`、自动交付一份稿子。
参考逐字稿只用于评分，不进入识别提示、词表或候选选择。

## 核查的资料

| 资料 | 可以借鉴的结论 | 本项目的限制与决定 |
| --- | --- | --- |
| [CB-Whisper，LREC-COLING 2024](https://aclanthology.org/2024.lrec-main.262/) | 先通过开放词汇关键词检测确认音频证据，再把实体和读音提示交给 Whisper；针对中文、英文和混说评估了实体召回 | 论文使用 TTS 和训练过的 CNN，不能把添加一段 prompt 称作复现。优先验证轻量关键词检测是否能提供独立证据 |
| [Fast Context-Biasing with CTC-based Word Spotter，Interspeech 2024](https://arxiv.org/abs/2406.07096) | 用 CTC 帧概率与上下文图匹配，仅在对应音频区间替换关键词；提供 NeMo 实现 | Whisper 没有 CTC 输出，不能直接套用。它支持“先定位、后局部修复”的设计，不支持全文模糊替换 |
| [Adopting Whisper for Confidence Estimation，2025](https://arxiv.org/html/2502.13446v1) | 音频与候选文本共同输入专门训练的置信度模型，比直接使用 softmax 分数更可靠 | 需要另外训练/分发模型；论文训练集是英文 Common Voice，不能直接声称适用于本项目中文会议。暂不加入运行依赖 |
| [Identifying and Calibrating Overconfidence in Noisy Speech Recognition，2025](https://arxiv.org/html/2509.07195v1) | 噪声下 Whisper 会高置信度出错；选择性温度校准改善置信度指标 | 研究使用 Whisper-medium.en 与受控噪声。ECE/NCE 改善不等于 CER/WER 降低；不能用重新缩放分数冒充识别提升 |
| [Contextual Biasing to Improve Domain-specific Custom Vocabulary，2024](https://arxiv.org/html/2410.18363v1) | 领域词表和前缀树可增强特定词汇识别 | 尽管标题强调不微调 Whisper，TCPGen 辅助网络仍经过训练，数据来自海事模拟。其数值不是中文会议的预期收益 |
| [CTranslate2 contextual biasing PR #1789](https://github.com/OpenNMT/CTranslate2/pull/1789) | logits 层可以做轻量序列偏置 | 核查时 PR 仍为 Open，不是已发布能力。直接增加分数还会改变用来选优的分数，不能将偏置后的分数当作独立音频证据 |
| [sherpa-onnx 开放词汇关键词模型](https://k2-fsa.github.io/sherpa/onnx/kws/pretrained_models/index.html) | 提供中英 3M 参数、音素建模的本地关键词检测模型，可输出命中时间 | 与 CB-Whisper、CTC-WS 是不同实现；需要实测漏检、误报、时间定位、发音词典与模型分发成本后再考虑接入 |

## 本轮取舍

1. 先补齐现有复核的诊断记录。记录原文、候选、两者模型分数及所有拒绝原因，
   区分保护规则、编辑量、重复和分数不足。只写入 JSON 内部诊断，默认稿件不显示候选，
   不要求用户选择。先确认该改动不影响原有文字、时序、说话人和已接受的纠错。
2. 对关键词检测做一次有边界的公开集可行性测试。使用固定词表和未出现的干扰词，
   同时检查正常语音、静音、噪声。检测成功不等于纠错成功，还必须检查对应时间和原词。
3. 保留数字、否定和大幅改写保护，先查清误拒候选。不能仅因规则可能过严就整体放开，
   也不能用参考稿挑选运行时的正确候选。

不开展大模型/阈值扫描，不把同一模型多次重试视作独立验证，不加入文字润色型 LLM，
不让用户配置模型、阈值或纠错流程。本地推理测量禁止网络，下载公开资料和模型除外。

## 验证约束

- 公开开发回放先于私人会议：FLEURS 普通话、ASCEND 混说、AMI 英文会议、静音和噪声。
- 同一音频前端、模型权重和 Metal 后端；记录二进制与输入指纹。
- 分开报告字错率、词错率、关键词命中、关键词误报和说话人指标。
- 公开回放和本次私人会议已经用于开发，不能重新命名为独立验收集。
- 新模块只有在固定公开样本上提供净收益且不增加错误关键词后，才考虑默认启用。

## 本轮实测结果

### 自动复核诊断

新增 `decoding_reviews` JSON 诊断，默认文本、SRT、VTT 不包含被拒绝的候选。
5 个公开回放的文字、片段、说话人时序、已接受纠错均与之前的最终构建完全一致。
普通话 CER 5.01%、混说 CER 17.62%、AMI ES2004c WER 20.85%；静音和噪声仍不出字。
35 分钟私人会议也保持完全一致，差异率仍为 20.94%。这是诊断能力增强，不是准确率提升。

私人会议的 45 次复核中，44 次缺乏足够的分数提升，9 次触及内容保护，9 次增加重复，
其中 1 次严重重复；拒绝原因可以重叠。仅移除内容保护不会增加任何被接受的候选。

以参考稿作事后诊断，逐个把候选代入固定全文评分：16 个候选降低编辑数、13 个提高、
16 个不变。16 个改善量相加仅 34 字，约 0.41 个百分点；这是各候选的单独贡献之和，
不是组合推理结果，更不是可部署选择器的成绩。其中一个重复失控的候选分数达 0.9535，
却增加 365 次编辑。不能通过简单降低分数门槛解决这个问题。

公开证据目录：`.cache/evaluation/review-evidence/`。私人候选分析保留在录音旁的
`asr-tool-review-evidence/`，不进入 Git。

### 轻量关键词检测可行性

固定使用官方默认检测参数、中英 3M 模型的 int8 encoder/joiner 与 fp32 decoder。
三个实际加载的模型文件合计 5,446,114 字节；这不是进程峰值内存。
测试没有修改 ASR 输出，也没有接入产品。

第一组词表由公开开发稿中的 15 个孤立实体及 15 个干扰词组成；这属于提供目标词表的
开发实验，不是盲测。词表固定后再用于另外两份 FLEURS、ASCEND、静音和噪声。

| 公开回放 | 参考词表出现数 | 检测命中 | 未匹配命中 |
| --- | ---: | ---: | ---: |
| FLEURS cmn 00 | 15 | 10 | 0 |
| FLEURS cmn 01 | 1 | 0 | 0 |
| FLEURS cmn 02 | 2 | 2 | 0 |
| ASCEND spk12 ses2 | 0 | 0 | 0 |
| 静音 60 秒 | 0 | 0 | 0 |
| 噪声 60 秒 | 0 | 0 | 0 |

约 20.5 分钟素材共检测到 12/18 个目标词，在这批样本中未观察到误报。匹配使用参考
句段范围和一秒容差，未验证精细词边界；因此不能把该数字等同于词级对齐准确率。
识别出一处主 ASR 写成“克隆群岛”的“科隆群岛”，但尚未实施文字替换。

随后用用户原有 prompt 中的 9 个纯中文词检测私人会议，未读取参考稿生成词表。
35 分钟素材检测约耗时 29 秒，命中某行业词 6 处、某专有名词 2 处。参考稿有 14 处
该专有名词，而两处检测中一处主 ASR 已正确。英文及混合字母词未纳入这次原型，不能
据此声称完成中英术语支持。该模型原样接入的预期收益有限，本轮不启用、不分发。

公开原型、固定词表、文件指纹及逐条结果位于 `.cache/evaluation/kws-research/`。
后续只有出现更强的中文声学证据或明显互补的候选生成方法，才值得继续这一方向；
校准、增大搜索宽度和扩充提示词都不应被当作已经验证的准确率解决方案。

## 后续实现：离线低音量语音恢复

继续优化时，先核对了上述模型实验，没有重复模型或阈值扫描。采用已有低音量公开
会议实验支持的音频前端改进：[FFmpeg dynaudnorm](https://ffmpeg.org/ffmpeg-filters.html#dynaudnorm)，
显式固定官方默认值 `f=500:g=31:p=0.95:m=10`，未按本批录音扫描参数。
它平滑调整增益，不是降噪或声源分离，不使用参考稿、文本润色模型或联网服务。

文件模式同时保留原始 PCM 和增强后的 PCM，检查样本数一致。声纹分段、嵌入和
复核始终使用原始 PCM；转写使用增强 PCM。原始、增强两次 VAD 的语音范围取并集，
合并交叠区间后再寻找停顿，防止增强处理漏掉原本已检测到的语音或产生虚假切点。
实时路径继续只用原始采集音频。参数固定在实现中，用户仍只提供录音和可选 `-p`。

早期仅使用增强 VAD 的版本，在 AMI IS1009a 上把 WER 从 31.27% 提高到 32.99%，
漏词从 135 增至 148；检测区间丢掉了原先覆盖的 5.27 秒。取并集后，该样本 WER
降至 30.76%。这项修改针对实际回归，不通过修改评分规则或放开纠错保护获得改善。
