# v2.0.0-rc.1

Maintenance prerelease for the local meeting and live transcription workflow.
It keeps the existing simple commands and does not replace the stable `latest`
release. Audio inference remains local.

## Fixes

- Fix Bash 5 installation failures, remove the installer test's ripgrep
  dependency, and pin a compatible Windows/Visual Studio/CUDA build environment.
- Keep the working installation when a download fails, validate downloaded
  payloads and notices, and respect the runtime's default model cache path.
- Reject truncated default models; isolate concurrent downloads and CoreML
  extraction; preserve literal Windows paths when invoking download tools.
- Return a model error for an unwritable cache and retain failure handling
  across native-library exception boundaries.
- Protect original recordings linked from output paths; isolate temporary
  audio files and reject truncated WAV data.
- Preserve literal VTT text, millisecond speaker timing, and valid JSON output.
- Drain live review before the end event; preserve errors instead of retrying
  an already-closed native stream or silently losing a failed submission.
- Mark failed acoustic alignment as approximate so unsupported token timing
  cannot invent a speaker change. Validate the required VAD model before
  transcription begins.
- Correct recovery metadata after a failed first decode, and reject recordings
  exceeding the native VAD sample limit instead of truncating their length.
- Include Windows runtime DLLs, propagate build-script failures, and initialize
  dynamic backends consistently for normal transcription and replay.

## Validation

Local Apple Silicon validation includes nine CTest cases, 61 Python evaluation
tests, Bash 3.2 and 5.3 installation tests, and missing/corrupt model checks.
The review details and CI failure evidence are in
[REVIEW-2026-10-16.md](https://github.com/xpfo-go/asr-tool/blob/v2.0.0-rc.1/docs/REVIEW-2026-10-16.md).

This repair release does not introduce new accuracy measurements. Existing
public evaluation results, their fingerprints, and practical limitations remain
in [EVALUATION.md](https://github.com/xpfo-go/asr-tool/blob/v2.0.0-rc.1/docs/EVALUATION.md).
No private meeting or microphone recording is used in this validation.

## Install

```bash
curl -fsSL https://github.com/xpfo-go/asr-tool/releases/download/v2.0.0-rc.1/install.sh | ASR_TOOL_RELEASE_TAG=v2.0.0-rc.1 bash
```

Prepare models once with `asr-tool --prepare-models` when migrating from 1.x.
Normal transcription does not download models.

```bash
asr-tool meeting.mp4 -p "project names, industry terms"
asr-tool meeting.mp4 -o meeting.json
asr-tool --live -o meeting-live.jsonl
```
