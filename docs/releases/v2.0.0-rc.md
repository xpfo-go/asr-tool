# v2.0.0-rc

This is a prerelease of the local meeting transcription workflow.
It does not replace GitHub's stable `latest` release.
Public results and remaining failures are published in
[EVALUATION.md](https://github.com/xpfo-go/asr-tool/blob/v2.0.0-rc/docs/EVALUATION.md);
product decisions and source references are in
[PRODUCT_DIRECTIONS.md](https://github.com/xpfo-go/asr-tool/blob/v2.0.0-rc/docs/PRODUCT_DIRECTIONS.md).

## Changes

- Single-device meeting transcription with local VAD, anonymous speaker labels,
  acoustic text timing, and explicit unknown/overlapping speech.
- Conservative audio re-decoding, preserving original text and accepted changes
  in JSON. User terminology stays in the existing `-p` prompt.
- macOS `--live` uses a local bilingual first pass and local review, with stable
  utterance IDs, JSONL provisional/revision/final events, bounded queues, and
  Ctrl-C draining. Audio is never sent to a server.
- Default files are saved beside the input. `-o meeting.json`, `.srt`, or `.vtt`
  selects the format without an extra flag; explicit `-f` takes precedence.
  Invalid output directories and attempts to overwrite the original recording
  fail before loading a model. Plain meeting text includes time/review markers.
- macOS capture objects use ARC. Native dependencies and notices are packaged;
  model files, public audio, and private recordings are excluded from Git.

## Migration From 1.x

Run `asr-tool --prepare-models` once after upgrading. Downloads happen only during
explicit preparation or installation. Normal transcription never downloads
missing models. ASR/VAD are required; missing speaker models produce text-only
output with a warning. The live models are additional preparation downloads.

Default output now goes beside the recording instead of the current directory.
Use `-o` to keep an existing automation's destination. Plain meeting text now
contains speaker/time/review markers. JSON preserves detailed uncertainty and
correction records. Live JSONL is a distinct event stream, not a file-mode JSON
document, and does not provide global speaker labels.

## Validation And Limits

Local Apple M2 Pro checks: Release build, six CTest cases, 61 Python evaluation
tests, installer checks, Skill validation, and native dependency inspection.
Public acceptance and replay details are recorded in the linked evaluation
report with executable, model, audio, and reference fingerprints. Inference
runs with network denied. No microphone or private recording is used in this
release validation. Real microphone permissions, device changes, and extended
capture still need hardware validation. Linux/Windows are subject to the CI
matrix; NVIDIA performance has not been measured locally.

Clear-Mandarin development CER is 8.10%, versus the 5% target. The frozen
101.57-minute meeting acceptance run measured Mandarin CER 60.98% and English
chronological WER 39.99%; attributed DER was 65.03% and 61.56% respectively.
Seven reserved mixed-language groups measured 14.97% aggregate CER, with a
50.32% worst group. One memory-pressure interruption was preserved; the remaining
groups completed after pressure normalized. Correction precision has not been
measured reliably. Three paced public live replays
measured aggregate CER 27.96% before review and 23.87% after review, with one
case regressing; pending review audio peaked at 10.4 seconds and sampled RSS at
2.41 GiB. A speaker number does not
identify a real person or establish who expressed a viewpoint. Text scores
are not interchangeable with speaker scores; review flags are not error rates.
No rejected alternative ASR/diarization model is installed by this release.
The live model export's commercial redistribution terms remain unverified;
weights are fetched directly from the publisher and are not bundled.

## Install The Candidate

After the release assets are available:

```bash
curl -fsSL https://github.com/xpfo-go/asr-tool/releases/download/v2.0.0-rc/install.sh | ASR_TOOL_RELEASE_TAG=v2.0.0-rc bash
```

```bash
asr-tool meeting.mp4 -p "project names, industry terms"
asr-tool meeting.mp4 -o meeting.json
asr-tool --live -o meeting-live.jsonl
```
