# 产品方向审查（2026-10-16）

本轮停止扩大模型候选，发布目标收敛为 v2.0.0-rc。定位仍是本机运行、
单设备多人会议、Apple Silicon 优先、用户不配置模型或人数。
商业级精准度是长期优化目标，不是本版本的发布门槛。私人会议测试继续暂停。

## 公开资料与判断

微信输入法[官网更新记录](https://z.weixin.qq.com/)提供了可核查的产品证据：

- Mac 2.0.0（2026-03-22，记录 144）：实时转写到输入框、连续输入、中英文混说。
- Mac 2.2.0（2026-05-27，记录 152）：去口水词、标点分段、归纳分点、理顺语序。
- Mac 2.2.3（2026-08-19，记录 168）：选择默认麦克风、切换窗口后不中断。
- Android 3.5.5（2026-10-09，记录 175）：单机模式可用离线语音。

这些是功能说明，没有公开可复现的 CER、DER 或纠错误改率，也没有证实各平台
共享同一个离线模型。不能据此宣称了解微信的内部算法或已达到它的准确率。
值得借鉴的是低操作成本、连续输入和输出可读性。归纳和调整语序属于文字整理，
不应直接混入需要保留原话与说话人观点的会议逐字稿。

[VoiceStudio](https://github.com/debpalash/VoiceStudio)核查版本：
`28d18023436229830debe8e65faf3eba4426f31b`。它是综合语音桌面应用；
本项目是轻量本地 CLI/Skill，两者不需要采用相同的运行栈。

- [asr_backend.py](https://github.com/debpalash/VoiceStudio/blob/28d18023436229830debe8e65faf3eba4426f31b/backend/services/asr_backend.py)
  使用 WhisperX/wav2vec2 做声学强制对齐；FunASR 路径提供 FSMN-VAD 和 CAM++。
  Apple Silicon 有 MLX 路径。源码中的时间精度和加速描述不是本项目实测结果。
- [refinement.py](https://github.com/debpalash/VoiceStudio/blob/28d18023436229830debe8e65faf3eba4426f31b/backend/services/refinement.py)
  只整理 final 文本；可选 LLM 默认有四秒超时，失败回退原文。其去重复、去填充词、
  自我修正是听写整理策略，不能直接等同于忠实的会议纠错。
- 本轮只借鉴工作流与失效回退原则，没有复制该项目代码或引入其 Python/LLM 服务。

## 投入顺序

| 方向 | 本项目证据与成本 | 决定 |
|---|---|---|
| 默认换更大的 Whisper | FLEURS CER 8.10% → 9.33%，英文会议也回归 | 停止，保留 Turbo |
| FireRed AED 替换 | ASCEND beam3 CER 12.64%，优于 Turbo 24.34%；清晰普通话未胜出，术语、声学对齐、分发仍有缺口 | 保留研究记录，不进入本次产品 |
| 新增 forced alignment 模型 | 产品已有 Whisper DTW；时间定位有价值，但额外模型无法修复聚类错人、漏字或重叠语音 | 暂不新增；未来先隔离测量归属误差 |
| 仅凭文本自动纠错和润色 | 更流畅不代表更忠实；可能改变数字、否定、承诺与观点 | 不作为默认逐字稿处理 |
| 自动路由多个 ASR/说话人模型 | 当前候选跨语言有回归；路由需要音频端的可靠判据，不能使用参考稿选模型 | 无独立收益证据，暂不实现 |
| 复用术语、局部音频复核 | 已实现 `-p`、保守重解码、原文记录；纠错成功样本仍少 | 保留，不夸大纠错准确率 |
| 降低使用和核对成本 | 不需要增加模型、配置或云服务，可用确定性测试验证 | 本轮优先交付 |

本轮交付：默认结果存放在输入文件旁，`-o meeting.json/.srt/.vtt` 自动选择格式，
显式 `-f` 优先；路径错误和覆盖原始音频在加载模型前拒绝；普通会议文本增加
时间位置与复核标记，JSON 保持结构化记录；修复采集对象内存管理，保留有界队列。
实时 JSONL 契约继续保持，`--live` 不推断发言人的真实身份。

以后启动新的准确率实验必须同时具备：明确的失败类型、可检查的上游能力、
固定对照数据和停止条件。不得用开发样本反复调参后把同一批数据称为独立验收。
完整数据与局限见 [EVALUATION.md](EVALUATION.md)。
